# Conjunct rules (যুক্তাক্ষর)

Conjuncts (যুক্তাক্ষর) are combinations of two or more consonants in Bengali script. The way you write a conjunct follows strict rules from Bangla Academy. The most common errors are: forgetting the যোজক, writing রেফ incorrectly, dropping the ল-ফলা, and applying the wrong vowel length.

This reference covers the four patterns that account for the majority of conjunct errors in Bengali tech writing.

---

## 1. যোজক (্) — the silent killer

The যোজক is a small diagonal stroke under a consonant that indicates it is joined to the next consonant without an intervening vowel.

### Forms

- ক্ষ = ক + যোজক + ষ
- ব্যবহার = ব + যোজক + য + ব + হা + র
- বাংলা = ব + আ + ং + ল + আ (the ঙ = ন + যোজক + গ, then the rest)

### Common errors

- **Forgetting the যোজক.** "অনেক" is correct (অ + ন + এ + ক — no conjunct). But "অনলাইন" should be "অনলাইন" — wait, "অনলাইন" has no conjunct either. Let me reframe.

The most common যোজক errors are inside loans and technical words:

- "প্রকাশ" → "প্রকাশ" is correct (প + যোজক + র + আ + কা + শ). The user might write "পরকাশ" (no যোজক) — wrong.
- "বিশ্ব" → correct (ব + ই + শ + ও). The যোজক is implicit in শ্ব = শ + যোজক + ব? No, শ্ব is just শ + ব (শ্ব as a ligature). The Bangla Academy form is "বিশ্ব" with শ্ব as a ligature.
- "দ্বন্দ্ব" → correct (দ + যোজক + ব + ন + যোজক + দ + যোজক + ব — five যোজক markers in one word).

### The simple rule

When two consonants are adjacent and no vowel is between them, you need a যোজক or a ligature.

- "পরকাশ" → "প্রকাশ" (যোজক between প and র)
- "সম্পূর্ণ" → correct (স + যোজক + ম + পূ + র + ণ — the যোজক is between স and ম, and ম is fused with প)
- "উদ্দেশ্য" → correct (উ + দ + যোজক + দ + ে + শ + যোজক + য়)

### Diagnostic

If a word looks like it should have a conjunct (two consonants next to each other with no vowel visible) and you cannot see a যোজক or ligature, the spelling is probably wrong.

## 2. রেফ (্র)

The রেফ is a small curve above a consonant that indicates the consonant is followed by র.

### Forms

- ক্র = ক + রেফ
- প্র = প + রেফ
- ব্র = ব + রেফ
- গ্র = গ + রেফ
- শ্র = শ + রেফ (e.g. শ্রম)
- স্মৃ = স + যোজক + ম + র (no রেফ — the র here is র after ম, not রেফ)
- ত্র = ত + রেফ (e.g. ত্রিভুজ, ত্রাণ)

### When রেফ is used

When the first consonant of a conjunct is followed by র, and the consonant can take a রেফ above it.

- ক্রম (ক + র), প্রকাশ (প + র), ব্রাহ্মণ (ব + র), গ্রন্থ (গ + র), ক্রমাগত (ক + র + ম + আ + গ + ত)
- শ্রম (শ + র), শ্রেণী (শ + র + ে + ণ + ী)

### When রেফ is NOT used

When the র is the second consonant and the first consonant does not take a রেফ above it, or when the র is just র after another consonant without conjunct.

- আমরা (আ + ম + র + আ) — no রেফ
- মরা (ম + র + আ) — no রেফ
- স্মৃতি — the র here is র after ম, no রেফ. The conjunct is স্ম = স + যোজক + ম.

স্মৃতি: স + যোজক + ম + র + উ + তি. The মৃ part is ম + র = মৃ. The র here is just র after ম. Both forms (র after ম, or রেফ over ম) are accepted.

### Common errors

- "করম" → "ক্রম" (রেফ over ক)
- "পরকাশ" → "প্রকাশ" (রেফ over প)
- "বরাহ্মণ" → "ব্রাহ্মণ" (রেফ over ব)
- "গরন্থ" → "গ্রন্থ" (রেফ over গ)
- "সরম" → "স্রম" (রেফ over স)? — no, the correct word is "শ্রম" (শ + রেফ). "সরম" is not a word.
- "পরসঙ্গ" → "প্রসঙ্গ" (রেফ over প)
- "পরশ্ন" → "প্রশ্ন" (রেফ over প)

### Diagnostic

If a word starts with what looks like প/ক/ব/গ/শ/ত/দ/স followed by র, and the র appears to be written as a separate letter র (not above the consonant), it is probably wrong. The র should be রেফ above.

## 3. ল-ফলা (ল written as a tail)

When ল follows another consonant and they form a conjunct, the ল is written as a "ফলা" (tail) below the consonant, not as a full ল letter.

### Forms

- কল্পনা = ক + ল-ফলা + প + ন + আ (the ল is below ক)
- বিশ্ব = ব + ই + শ + ও + ব — wait, this is wrong. "বিশ্ব" has ল? No. Let me reframe.

Let me give actual ল-ফলা examples:

- কল্পনা = ক + ল-ফলা + প + ন + আ
- বিশ্ব = ব + ই + শ্ব — no ল. Skip.
- ফল = ফ + ল-ফলা
- পূর্ণ = প + ূ + র + ণ — no ল. Skip.
- ক্ষমা — no ল.
- হলুদ = হ + ল + ু + দ — full ল here (ল as a separate letter, not ফলা). Because in হলুদ, the ল is preceded by হ (a vowel-bearing consonant) and followed by ু — it's just ল.

OK so the rule is:

### When ল-ফলা is used

When ল is the second consonant in a conjunct and the first consonant has the যোজক. The ল is written as a tail below the first consonant.

- কল্পনা (ক + ল as conjunct)
- দুলি (দ + ু + ল + ি) — the ল is a full letter here, not ফলা, because there is no যোজক.

**ল-ফলা is used in conjuncts where ল is the second consonant after another consonant, AND the conjunct is a recognized Bangla Academy form.**

Examples of words using ল-ফলা:
- কল্পনা (imagination)
- কল (time, machination — wait, "কল" is debated)
- ফল (fruit)
- চল (mobile)
- দুল (swing)
- ছল (trick)
- জল (water)
- তল (floor, depth)
- নল (pipe)
- বল (strength, ball — debated)
- মল (dirt)
- শল (pike, fish-bone)
- হল (hall, also past of হওয়া)
- গল (neck, throat)
- ডল (lump)
- ঢল (torrent)
- ভল — not a word
- সল — not common
- রল — not a word

So a single ল letter after a consonant (without a vowel between) usually means ল-ফলা (tail) in the conjunct form.

### Common errors

- Writing "কল্পনা" with full ল (ক + ল + প + ন + আ) instead of ল-ফলা (ক + ল-ফলা + প + ন + আ). This is a stylistic choice; both are sometimes accepted, but the Bangla Academy form is ল-ফলা.
- Writing "ফল" as "ফল" (correct, with ল-ফলা) — wait, this is correct. The error would be writing "ফল" as "ফল" with full ল — but in modern Unicode rendering, both look similar; the difference is in the underlying glyph form.

For the purpose of this skill: do not flag a word where the ল-ফলা form is the canonical one. Do flag in CHANGES if the user wrote "কলপনা" (without যোজক + ল), which is wrong — should be "কল্পনা".

## 4. হ্রস্ব / দীর্ঘ vowels (স্বরবর্ণ)

The vowels ই/ই, উ/ঊ, and the consonant-vowel endings.

### হ্রস্ব ই (ি) vs দীর্ঘ ঈ (ী)

**হ্রস্ব ই (ি):**
- কিছু, কিতাব (older spelling of কিতাব — modern prefers কিতাব with হ্রস্ব)
- দিওয়া, দিয়ে (give), খিলি, ইট, ইদুর, ইমন
- Pronouns: কি (what), এই (this), ঐ (that)

**দীর্ঘ ঈ (ী):**
- কী (why / what), যী (an ascetic), ভী (fear — rare)
- Words ending in -ী: নদী, হরিণী, মী, গী, সী
- বাড়ী — older spelling, modern Bangla Academy uses বাড়ি (হ্রস্ব)

### হ্রস্ব উ (ু) vs দীর্ঘ ঊ (ূ)

**হ্রস্ব উ (ু):**
- তুমি, মুখ, খুব, ছুটি, বুঝ, রুটি, গুন, কুল, কুমির, ভুল
- Verb stems: শুন (hear), ঘুম (sleep)

**দীর্ঘ ঊ (ূ):**
- ভূমি, নূপুর, ভূত, কূপ, সূর্য, মূল্য, মূল
- তৎসম with দীর্ঘ: পূর্ণ, পূজা, ধূলা, চূর্ণ, দূর, দূত

### Quick rules

| Word pattern | Vowel | Why |
|---|---|---|
| কিতাব, কিছু, দিয়ে | হ্রস্ব ই | Native Bengali |
| নদী, হরিণী, কী | দীর্ঘ ঈ | Native Bengali or specific তৎসম |
| তুমি, মুখ, খুব | হ্রস্ব উ | Native Bengali |
| ভূমি, নূপুর, সূর্য | দীর্ঘ ঊ | তৎসম |

### Common errors

- "কীছু" → "কিছু" (হ্রস্ব ই)
- "ভুমি" → "ভূমি" (দীর্ঘ ঊ)
- "নুপুর" → "নূপুর" (দীর্ঘ ঊ)
- "সুর্য" → "সূর্য" (দীর্ঘ ঊ)
- "মুল্য" → "মূল্য" (দীর্ঘ ঊ)
- "পুর্ণ" → "পূর্ণ" (দীর্ঘ ঊ)
- "পুজা" → "পূজা" (দীর্ঘ ঊ)
- "করিম" — not a word; করিম is a name (Kareem) where the long ঈ can be argued. Keep the user's choice.

## 5. তৎসম words retain Sanskrit spelling

This is a meta-rule that overrides the modern pronunciation. তৎসম (Sanskrit-origin) words keep their Sanskrit spelling even when Bengali pronunciation differs.

### Examples

- অন্ন (food) — pronounced অন্ন but spelled with double ন্ন (the যুক্ত ন্ন)
- সূর্য (sun) — pronounced শূর্য or সূর্য but spelled সূর্য
- মূল্য (price) — pronounced মূল্য but spelled মূল্য
- বিশ্ব (world) — pronounced বিশ্ব or বিশ্ব (with যুক্ত শ্ব)
- দ্বন্দ্ব (conflict) — pronounced দ্বন্দ্ব but spelled with the যোজক-ব markers
- ধন্যবাদ (thanks) — pronounced ধন্যবাদ but spelled ধন্যবাদ (with যুক্ত ন্য)

### Common errors

- "সুর্য" → "সূর্য" (দীর্ঘ ঊ required in তৎসম)
- "মুল্য" → "মূল্য" (দীর্ঘ ঊ)
- "অন" → "অন্ন" (তৎসম যুক্ত ন্ন)
- "বিস্ব" → "বিশ্ব" (তৎসম যুক্ত শ্ব)
- "ধন্যবাদ" → "ধন্যবাদ" (তৎসম যুক্ত ন্য)
- "সংস্কৃত" → stays as is (তৎসম, all যুক্ত forms correct)

## 6. Conjuncts that are easy to forget

These conjuncts are commonly dropped or mangled in tech writing:

| Correct | Common wrong | Why |
|---|---|---|
| ব্যবহার | বাবহার / বয়াবহার | যোজক ব + য + ব |
| বিশ্ব | বিস্ব | যুক্ত শ্ব |
| প্রয়োজন | পরয়োজন | রেফ over প |
| সম্ভব | সমভব | যোজক ম + ভ |
| সম্পূর্ণ | সম্পুর্ন / সম্পূর্ন | যোজক ম + প, ণ not ন |
| সম্মান | সামান | যোজক ম + ম |
| প্রচুর | পরচুর | রেফ over প |
| প্রশ্ন | পরশ্ন | রেফ over প |
| সতর্ক | সতরক | যোজক ত + র (or রক is the root) |
| দ্বিধা | দিধা | যোজক দ্ব = দ + ব |
| দ্বারা | দারা | যোজক দ্ব + আ + র + আ |
| নির্ভর | নিভর | যোজক নি + র্ব = নির্ভর (with র্ব as conjunct) |
| নির্বাচন | নিবার্চন | যোজক নি + র্ব = নির্বাচন |
| জ্ঞান | জান / গ্যান | Conjunct জ্ঞ mandatory |
| ক্ষমা | কখমা / কশমা | Conjunct ক্ষ mandatory |
| বিষণ্ণ | বিষন্ন / বিষন্ণ | Double ণ, not ন |

## Diagnostic flow

When you see a Bengali word that looks unfamiliar:

1. **Does the word have a conjunct?** Count the consonants. If two consonants are adjacent with no vowel, it might be a conjunct.
2. **If a conjunct, which form?** Check: যোজক, রেফ, or ল-ফলা.
3. **If the word is তৎসম**, apply the দীর্ঘ vowel rule from §5.
4. **If unsure**, leave the word unchanged and flag as **needs verification** in the MISUNDERSTANDINGS section (not CHANGES — CHANGES is for confident fixes).

---

## What this skill does NOT do

- It does not "modernize" spellings that have multiple accepted forms (e.g. তৎসম vs তদ্ভব — keep the user's choice if both are valid).
- It does not insert অপিনিহিত (inherent অ) where the user has omitted it intentionally (e.g. in poetry).
- It does not flag every যোজক inconsistency as an error — some flexibility is allowed.

When in doubt, flag as **needs verification** rather than guessing.
